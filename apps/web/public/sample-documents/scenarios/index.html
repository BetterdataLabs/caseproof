Every flow has a case to try.

21 scenarios with fictional business documents, named participants, exact actions and expected results. Start with a clean review, then explore exceptions and recovery.

Download all scenariosOpen testing guide
How to use these documents
  1. Sign in as Alex Chen. Start a NEW case for each scenario and use only that folder's files.
  2. One case is one sale. The seller issues the invoice; the buyer or a permitted logistics provider confirms receipt. Different letterheads do not mean different sales.
  3. Most scenarios use Your documents. Scenarios 17, 20 and 21 use the named Demo scenario so the clock, withdrawal and structured-response controls are available.
  4. Upload only the Start with files. Keep reference templates in the optional reference fields. Leave Written message blank unless the instructions provide wording.
  5. Wait for each agent run to settle. For a correction, select the exact earlier source under Replacing an earlier document?. For another delivery, select No - adding new evidence.
  6. Use the sample policy unless a scenario explicitly requires a published change. A case can correctly finish on hold or remain open when evidence is unsafe or unsupported. Document review never approves financing.
