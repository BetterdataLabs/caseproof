CASEPROOF | A COPIED RECEIPT COUNTS ONCE

A repeated PDF must not turn one delivery into two.

Seller: Beacon Storage Supplies Pte Ltd
Buyer: Willow Logistics Pte Ltd
Invoice: BS-2026-4401
Flow: duplicate_receipt

SETUP
Use the sample policy; optional document checks off unless specified.

START WITH
01-invoice.pdf
02-first-receipt-60.pdf
03-copy-of-first-receipt.pdf

EXPECTED FIRST RESULT
The invoice is SGD 2,400.00. Files 02 and 03 are identical copies of one receipt: coverage must remain 60 of 100 boxes, not 120.

STEPS
1. Create a new case with 01 as the invoice. Select BOTH 02 and 03 in Delivery receipt PDFs in the same upload.
2. Leave Written message blank. Wait for the agent and confirm only 60 boxes count. The duplicate can be suppressed rather than displayed as a separate source.
3. Add 04 as a Delivery receipt PDF. Keep replacement set to No - adding new evidence.
4. Wait for the agent. Coverage should become 60 + 40 = 100 boxes. If you try uploading an already saved PDF again, an Already received message is also valid behaviour.

EXPECTED FINAL RESULT
The extra copy never increases coverage. Only the new second delivery brings coverage to 100 and allows completion.

FILES
01-invoice.pdf: invoice
02-first-receipt-60.pdf: receipt
03-copy-of-first-receipt.pdf: receipt (identical copy of 02-first-receipt-60.pdf)
04-second-receipt-40.pdf: receipt

All companies, people, addresses and transactions are fictional.
The business PDFs are test records, not genuine invoices or evidence of real deliveries.
