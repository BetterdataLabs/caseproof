CASEPROOF | DISPATCHED DOES NOT MEAN RECEIVED

The seller's dispatch note is not the buyer's receipt acknowledgement.

Seller: Lakeside Maintenance Supply Pte Ltd
Buyer: Riverside Property Services Pte Ltd
Invoice: LM-2026-6601
Flow: dispatch_not_receipt

SETUP
Use the sample policy; optional document checks off unless specified.

START WITH
01-invoice.pdf
02-seller-dispatch-note.pdf

EXPECTED FIRST RESULT
The SGD 2,150.00 invoice is correct. The dispatch note says goods left the seller; it does not prove the buyer received them. Expect the note to be flagged and buyer receipt evidence to be requested, possibly through a review task.

STEPS
1. Start with 01 as the invoice. Deliberately put 02 in Delivery receipt PDFs to test whether the app rejects dispatch as proof of receipt. Leave Written message blank.
2. Wait for the agent. Confirm that the dispatch note does not count as 50 cartons received. A flagged document or an evidence-review task is expected, not an app failure.
3. Add 03 in Delivery receipt PDFs. Keep Replacing an earlier document? set to No: a buyer's receipt is new evidence, not a replacement for the seller's dispatch note.
4. After the buyer receipt is accepted, open the Rejected document decision. Choose Exclude this rejected document from the review. Reason: The seller dispatch note is not receipt evidence; the buyer receipt independently confirms all 50 cartons.

EXPECTED FINAL RESULT
The rejected dispatch note remains in history and counts toward no check. The buyer receipt covers all 50 cartons, and the recorded exclusion allows completion.
