Four business-style, text-searchable PDFs with fictional companies and transactions.
The invoice and buyer-issued goods-received notes have distinct letterheads, addresses,
line-item tables, commercial references, dates, document versions and acknowledgements.

START WITH THESE TWO FILES
  01-invoice.pdf: NQ-1042 v1. 100 boxes at SGD 25 each; the stated amount is intentionally
  wrong (SGD 2,600 instead of SGD 2,500), so you can test the invoice check.
  02-first-receipt.pdf: Buyer receipt MR-701 for delivery DEL-701: 60 boxes received.

1. New case > Your documents. Select 01 as the invoice and 02 as a receipt. Start review.
   The agent should request an invoice correction and receipts for the missing 40 boxes.
2. Add documents or reply. Select 03-corrected-invoice.pdf as an invoice and select the
   original invoice under 'Replacing an earlier document?'. The invoice total is now 2,500.
3. Add 04-remaining-receipt.pdf as a delivery receipt. Leave replacement set to 'No'.
   MR-702 records a distinct delivery DEL-702 of 40 boxes. The review should complete.

Wait for the agent to finish each step before sending the next document.
Do not upload all four files as initial evidence; 03 is a correction, not another invoice.
Use a new case for these redesigned files rather than mixing them with the older samples.
